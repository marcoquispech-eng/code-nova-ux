# Code Nova — Rediseño UX/UI

Formulario de registro reconstruido y mejorado a partir de un trabajo
del primer ciclo.

Incluye validaciones, mensajes de estado, mostrar u ocultar contraseña,
limpieza con confirmación y diseño adaptable.

El registro es una simulación y no almacena datos ni contraseñas.
